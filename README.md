# Muhammad Imam Nurokhi — Portfolio

Personal portfolio website for **Muhammad Imam Nurokhi**, IT Product Architect & Full Stack Developer.

Built with **Next.js 15**, **Tailwind CSS**, and **Framer Motion** — featuring a "Digital Glassmorphism Arsitektural" design theme.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Forms**: React Hook Form + Zod validation
- **Fonts**: Inter (sans-serif) + Playfair Display (serif) via Google Fonts
- **Language**: TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

## Sections

- **Hero** — Typing animation, animated grid background, stat cards
- **Tech Stack** — Expertise cards + interactive technology arsenal grid
- **Experience** — Animated vertical timeline with career history
- **Projects** — Bento grid layout with case study modals
- **Contact** — Validated contact form with micro-interactions
- **Footer** — System status badge, digital signature animation
